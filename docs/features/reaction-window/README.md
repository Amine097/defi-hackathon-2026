# Reaction Window · P2

**Goal:** estimate the time available before a liquidation threshold in a scenario specifying market developments or withdrawals.

The [Impact Analyzer specification, §8d](../whale-impact/spec.md#8d-time-left-to-exit-countdown) describes the expected assumptions and ranges. [Breaking Point](../breaking-point/README.md) provides a shock threshold, but is not sufficient to infer a delay without a speed model.

**State:** specified; unidentified dedicated temporal calculation.
