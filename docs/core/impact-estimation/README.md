# Impact Estimation

**Goal:** propagate a dependency shock to the affected positions and estimate an explainable financial loss.

**Code:** `src/defirisk/propagation.py` runs the simulation; `public/assets/js/xray/model.js` calculates the impact for interactive exploration.
