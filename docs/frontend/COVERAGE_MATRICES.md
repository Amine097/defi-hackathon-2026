## Matrix B — backend → design

Drafted from the backend source (sections below), then reconciled with the integration.

### How to read

- One row per implemented, user-facing backend feature. Row IDs (A = analyze, V = vault, C = countermove, R = RescueVault,
  K = keeper, S = scripts) are referenced in §8–§10.
- **Coverage:** YES = every user-relevant output and parameter has a matching design element · PARTIAL = some outputs shown
  (often as constants in `faultline-data.js`) or controls/states missing · NO = no matching element, or the design states the
  feature does not exist.
- **Screens:** LAND landing · SEL select position · LOAD loading · SHELL top bar/nav · DASH dashboard · POS Positions & Vaults ·
  XR-I / XR-S / XR-R X-Ray Inspect / Simulate attack / Replay incident · CM-1 / CM-2 / CM-3 Countermove Policy preview / Fork
  demonstration / Autonomous protection · ACT Activity & Evidence.
- **Infra:** PUB-RPC = public Ethereum JSON-RPC (`ETH_RPC_URL` first if set, else drpc / blastapi) · PENDLE = Pendle API v2 +
  SDK convert · MGQL = Morpho GraphQL (`blue-api.morpho.org`) · LLAMA = DefiLlama (hacks, protocols, coins, stablecoins) ·
  V60 = Vercel Python function, 60 s max.
- **Tests** (`tests/`): tc test_compliance · th test_hardening · tb test_belem_review · tdc test_decision_coherence ·
  tl test_lineage · tpf test_portfolio · tpl test_pipeline · thc test_http_cache · tv test_vault · tvp test_vault_p0 ·
  tvl test_vault_live · tca test_countermove_api · tcd test_countermove_dryrun · tce test_countermove_e2e (needs Anvil) ·
  tcg test_countermove_engine. (`contracts/test/`): RV RescueVault.t.sol · RVF RescueVaultFork.t.sol ·
  RVI RescueVaultInvariant.t.sol · RVT RescueVaultTokens.t.sol. "(live)" = skipped unless `DEFIRISK_LIVE_TESTS=1`.

### 0. Cross-cutting backend facts the design must absorb

1. **Surface.** Three Vercel Python functions, GET only, no auth, no POST, no sessions/persistence, no wallet, no job ids or
   streaming → the 6 loading steps are cosmetic. Recorded durations: analyze 28.1–28.9 s, vault 11.9 s; countermove recorded
   run is instant, dry run a few seconds. `maxDuration` 60 s → a slower run ends in a platform 504 (not JSON).
2. **Two error-body shapes.** analyze: flat `{error, code[, hint]}` (400 `invalid_input`, 502 `discovery_failed`).
   vault and countermove: nested `{error: {code, status, message, …}}`.
3. **Caching.** analyze sends `s-maxage=60` on every status (also 400/502); vault `s-maxage=30` on 200 and `no-store` on
   errors; countermove `no-store`.
4. **No silent fallback.** analyze returns 502 when live discovery fails (its docstring still mentions `mock-fallback`; the
   code no longer does it). Demo graph only on explicit `ref=mock` (`source: "mock"`, verdict forced to REVIEW). Disk-cache
   replay (`source: cache/mixed`; vault `mode: cache/offline`) only where the gitignored `data/cache/` exists (local dev).
5. **Fixed vs free parameters.** analyze horizon is fixed at 30 d (no parameter); vault `horizon_days` 1–365. Defaults:
   analyze `value_usd` 1,000,000; vault `value_usd` **100,000** (the design shows $1M for both).
6. **Provenance vocabularies.** analyze `source` live/cache/mixed/mock + `decision.freshness.label` fresh/stale/replay/mock;
   vault `mode` live/cache/mixed/offline; countermove SIMULATED, CONFIRMED, FAILED, NO_ACTION, LIVE (`live=1`); dry run
   LIVE + DRY-RUN. Design chips today: RECORDED LIVE RUN, LOCAL FORK, SIMULATED, DRY RUN, FORK CONFIRMED, MAINNET CONFIRMED,
   HISTORICAL DATA, PENDING, UNAVAILABLE.
7. **Scope.** Ethereum mainnet only. analyze = listed Morpho markets (≥ $1M supply) taking a Pendle PT as collateral; vault =
   factory-verified Morpho V1/V2 vaults; dry run = any Morpho Blue market with collateral + oracle; Countermove execution =
   local Anvil (chain 31337) only. No wallet → positions discovery.
8. **Deployment constraints.** `vercel.json` CSP: `connect-src 'self'`, `script-src 'self'`, `font-src 'self'` → the browser
   can only call these three endpoints (no direct RPC/wallet RPC); fonts and scripts of the design export must be bundled
   and self-hosted. Artifacts outside `public/` (`data/fixtures/replay_h04.json`, `audit/*.json`, `docs/core/*.json`) are
   not fetchable at runtime unless copied into `public/` or exposed by an endpoint.
